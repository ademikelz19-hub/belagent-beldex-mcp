03 / TRANSPARENCY

Demo vs. live

Demo mode simulates the wallet outcome, without creating a blockchain transaction. Testnet mode calls the injected Beldex wallet, still requiring an actual user decision.

A wallet-returned transaction hash is marked unverified until independently reconciled. This POC never claims on-chain settlement based only on browser data.
